# Walkthrough Lucimara — 26 outubro 2026

**URL:** https://www.mitiga.online  
**Conta demo:** `lucimara@mitiga.com` (MITIGA Demo Ltd.)  
**Duração alvo:** 8–10 minutos  
**Regra:** ela conduz o mouse; você só aponta o próximo clique se travar.

## Antes de começar

1. Abrir só `https://www.mitiga.online` (com `www`).
2. Hard refresh (Cmd+Shift+R) se a sessão for antiga.
3. Confirmar sidebar: Home · Customers · Suppliers · Access.

## Roteiro (ordem fixa)

### 1) Home — “Onde estou?”

- Mostrar empresa no topo (**MITIGA DEMO LTD.**) e e-mail no rodapé da sidebar.
- Ler: **What do you want to do?**
- Frase: “Três módulos reais: clientes, fornecedores e acessos.”

### 2) Customers — fila de risco

- Clicar **Go to customers** (ou menu Customers).
- Mostrar o snapshot: `3 customers · 1 low · 0 medium · 2 high`.
- Frase: “Isto é a fila do dia — quem está Low/High.”

### 3) Blake — resultado autoexplicativo

- Abrir **Blake Sample (DEMO-002)**.
- Começar pelo **Latest risk result** (não pelo perfil).
- Se aparecer **How to read this**: explicar em uma frase — “regra dura (PEP/screening) sobe a faixa mesmo com score baixo; seguimos banda, EDD e outcome.”
- Abrir **Why this result** só se ela perguntar o detalhe.

### 4) Casey (opcional, 1 min)

- Voltar à lista → **Casey Placeholder**.
- Se for reject: mostrar o alerta vermelho — “não onboard; reportar ao MLRO.”

### 5) Access — quem fez o quê

- Menu **Access**.
- **People:** papéis na empresa (You = Lucimara).
- **Recent activity:** avaliações / memberships registrados.
- Frase: “Rastro auditável — não é planilha solta.”

### 6) Suppliers (opcional / corte)

- Só se sobrar tempo. Se atrasar, **pular** (regra do plano de 10 dias).

### 7) Fechar

- Voltar Home → **Sign out**.
- Pergunta de fechamento: “Ficou claro o caminho Cliente → resultado → Access?”

## O que não dizer

- “Ainda estamos conectando / esta tarefa / database / RSC / deploy.”
- “Isso é protótipo sem formatação.”
- Detalhe de engine v1.1 / TASK-036 (fora do escopo desta demo).

## Se algo quebrar ao vivo

| Sintoma | Ação |
|---|---|
| Tela sem CSS / Times | Cmd+Shift+R; URL com `www` |
| “No workspace yet” | Sair e entrar de novo |
| Access vazio | Continuar com Customers; Access é secundário |

Ela consegue repetir sozinha: **Home → Customers → Blake → Access**, sem script na mão.
